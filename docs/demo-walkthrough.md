# Demo Walkthrough

Use this flow when demoing the product to a coaching company such as Hungry Horse Poker.

## 1. Log in as owner or coach
- Open `/login`
- In demo mode, use one of the seeded demo accounts shown on the page
- Start with the **Coach** account if you want to emphasize operations and member management

## 2. Show the admin view first
Focus on why this is useful to a training business:
- user counts by role
- assignment queue
- audit logs
- organization/member scaffolding
- weakest-scenario / weakest-villain analytics

## 3. Show the dashboard from a member account
Emphasize that the product is not just a sandbox:
- assignments queue
- suggested practice generated from actual weak spots
- recent hands and results
- ability to resume work

## 4. Open results and a hand debrief
Show how the platform reinforces the teaching system:
- villain's true hand and final bucket
- whether the user kept the real hand alive
- whether the response prediction matched the actual action
- short coaching takeaways

## 5. Launch directly into a targeted drill
Use a quick-start link from an assignment or suggested-practice card.

Pitch framing:
- this is the **practice and assessment layer** for a coaching curriculum
- it turns repeatable thought process into measurable reps
- it helps members retain what they learned between camps/coaching sessions
